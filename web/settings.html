Add to Plex

Each Plex server gets two providers, one for movies and one for TV, both pointing at this container.

Include the port. Use a local address, never one behind a login page: Plex can't sign in. Servers on different networks may need different addresses.

Movies
TV
  1. In Plex: Settings → Metadata Agents → Add Provider, once for each address.
  2. Create an agent with Plex Movie or Plex Series as the Primary (it can't be changed later), add Mediux Artwork, and drag it to the top.
  3. Pick that agent for a library under Edit → Advanced, then refresh.

Pick a set

Type to narrow your library below, then click a title. For a title that isn't in your library, use Search Mediux. Choose a set separately for the poster, background, season posters and title cards. Your pick wins over AURA and creator priority; anything you don't pick follows the usual rules.

    Share the folder holding AURA.db with this container read-only. For example, add - /mnt/cache/appdata/aura/unlimited-primary:/aura:ro under volumes: in the compose file, and the path here is /aura/AURA.db. Leave empty to turn it off.

    Watch for new artwork

    Plex only asks for artwork when a title is added or refreshed. Watching re-checks Mediux for titles Plex has asked about, so a title card uploaded a week after the episode still arrives.

    Checks are spread out, 150 titles every 10 minutes, to go easy on Mediux.

    Plex servers

    When new artwork turns up, these servers are asked to refresh just that title. Use addresses this container can reach, with your Plex token for each server.
