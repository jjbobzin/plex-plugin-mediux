Add to Plex

Add both addresses in Plex under Settings → Metadata Agents → Add Provider.

Include the port, the one on the left of ports: in your compose file. Use the local IP, never an address behind a login page (like Pangolin): Plex can't sign in.

Movies
TV
  1. Create an agent with Plex Movie (or Plex Series) as the Primary. The Primary can't be changed later.
  2. Add Mediux Artwork to that agent and drag it to the top, so its artwork wins.
  3. Set a library's agent to it (library → Edit → Advanced), then refresh to apply.
